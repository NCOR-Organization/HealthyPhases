Schedule a saved query

Search for papers first, then choose the saved search below. Its query, dates, sort order and result limit are preserved.

First run: one interval after creation. Schedules run while the orchestrator is available. Downloading skips papers already published or queued. Searches retain their result limit; narrow broad queries to avoid missing papers. Phase v2 runs remain separate.

Full ingestions

Find every matching record and download the available PDFs in batches. Saved date filters still apply.

There is no total-paper limit. Discovery continues until every matching range has been processed. Published PDFs are reused. PubMed can change while a large ingestion is running, so the initial match count is an estimate.
